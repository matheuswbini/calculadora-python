# Calculadora em Python

Uma calculadora simples feita em Python, com menu interativo no terminal.

Projeto de estudo para praticar lógica de programação, funções e estruturas de repetição.

## Funcionalidades

- Soma
- Subtração
- Multiplicação
- Divisão (com tratamento de erro para divisão por zero)

## Como executar

1. Clone o repositório:
```bash
git clone https://github.com/matheuswbini/calculadora-python.git
```

2. Acesse a pasta:
```bash
cd calculadora-python
```

3. Rode o programa:
```bash
python calculadora.py
```

## Como usar

Ao rodar o programa, um menu aparece no terminal:

```
===== CALCULADORA =====
1. Soma
2. Subtração
3. Multiplicação
4. Divisão
0. Sair
========================
```

Digite o número da operação desejada, depois os dois números que você quer calcular. Digite `0` para sair.
